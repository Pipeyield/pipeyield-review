# Security

To report a security problem in this plugin, or in Pipeyield's website or review service, email **hello@pipeyield.com**.

Please include what you found and the steps to reproduce it. Please don't open a public issue for a security problem.

We read every report and reply by email.

## What this repository holds

Only the plugin: its manifest, one skill file of instructions for Claude, and the README. The review itself runs on Pipeyield's server. The plugin never connects to a Google Ads account, and the search terms file is uploaded on pipeyield.com, not through the chat.
